Title:
NOAA Weather → Morse Code Audio Alert System
Description:
A Python script that fetches the latest NOAA weather report, converts it into Morse code audio, uploads the file to a hosted webpage, and sends an email notification to subscribers.
Why This Project Matters:
Combines radio + programming
Real data pipeline
Automation learning
Audio generation
Deployable and useful
A project you can show other hams
VERSION 1 Goal (MVP):
Fetch NOAA weather → convert to Morse code WAV file → save locally.
We will expand later with hosting + email.
